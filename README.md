# NightHawk

<img src="https://raw.githubusercontent.com/z1gres/nighthawk/main/assets/img/preview.png" alt="NightHawk Banner" width="700">

> NightHawk is a powerful 0S1NT tool that combines fast username and email searches across more than 600 platforms. By leveraging community-driven projects like WhatsMyName, it ensures low false positive rates and high-quality results. Features include smart filters, polished PDF/CSV exports, and fully automated analysis — all from a single CLI.
<br>

### Setup

**Clone the repository**

```bash
git clone https://github.com/z1gres/nighthawk
cd blackbird
```

**Install requirements**

```bash
pip install -r requirements.txt
```

### Usage

```bash
python nighthawk.py
```

**Simple version**

```bash
python nighthawk.py --simple
```
